# SPITITOUT

A quick, read-only way to see what's on your Mac.

It shows your Homebrew formulae, casks, and installed apps in one place, so you don't have to type a pile of commands just to see what you've got.

No accounts, no telemetry, no database. Just your Mac.

## Requirements

- macOS
- Zsh
- Homebrew (optional)

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/willowio/spititout/main/install.sh | bash
```

## Then:

```sh
spititout
```

## Uninstall

```sh
spititout zap
```

SPITITOUT will ask for confirmation before removing itself.
